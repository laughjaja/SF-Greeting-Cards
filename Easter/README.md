# Easter

This folder contains the active Easter greeting card build and related assets.

## Structure
- `app/` - the Next.js/Vercel project for the interactive card and hosted assets
- `email/` - email-safe exported assets for Easter sends
- `notes/` - event-specific notes and follow-ups

## Key outputs
- `app/public/card.html` - standalone HTML card
- `app/public/card-video.html` - hosted video player page
- `app/public/card-video.mp4` - hosted video export
- `app/public/card-video-email.gif` - hosted email-safe GIF
- `app/public/email-template.html` - hosted email-safe HTML preview
- `email/email-template.html` - copyable sendable email template
- `email/card-video-email.gif` - email GIF asset

## Notes
- This folder is self-contained so future events can follow the same structure without mixing files.

# Easter

This folder contains the active Easter greeting card build and related assets.

## Structure
- `app/` - the Next.js/Vercel project for the interactive card, video, GIF, and email template assets

## Key outputs inside `app/public/`
- `card.html` - standalone HTML card
- `card-video.html` - hosted video player page
- `card-video.mp4` - video export
- `card-video-email.gif` - email-safe GIF
- `email-template.html` - email-safe HTML template

## Notes
- This folder is self-contained so future events can follow the same structure without mixing files.

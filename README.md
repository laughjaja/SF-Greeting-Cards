# SF Greeting Cards

A dedicated repo for Sarah Fell greeting email concepts and sendable email builds.

## Current files
- `sendable-email-template.html` - neutral, email-safe wrapper for the greeting email
- `concept-preview.html` - preview-oriented concept shell
- `brand-notes.md` - tone, palette, and design direction aligned to the Sarah Fell site
